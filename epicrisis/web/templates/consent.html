Model processing

What goes to a model, where it goes, and what is never sent. Nothing leaves this server before you say so here.

What is sent
The full image of a page, or all of its text, with everything printed on it, including names, dates of birth and results. {% if pages %}This run will send {{ pages|thousands }} pages from {{ files|thousands }} files, each in a request of its own, and some of them more than once — a page whose reading a check did not agree with is read again by a stronger model{% if archives|length > 1 %}, out of every archive on this server — {{ archives|join(", ") }}{% endif %}.{% else %}No pages are ready to send yet.{% endif %} Epicrisis removes the file name, folder names, paths and image metadata. Where it goes
{% if engine == "anthropic-api" %}
To Anthropic, straight from this server to the API, with a key of your own from a .env file beside the data folder. Your own account, your own bill.
{% else %}
To Anthropic, through Claude Code signed in with your own Claude subscription on this server. This mode is meant for personal use.
{% endif %}
What happens to it there
{% if engine == "anthropic-api" %}
The terms of the account the key belongs to apply — commercial terms for an organisation account, consumer terms for a personal one — and they decide how long data is kept, whether it may be used for training, and what review is possible. Read the terms of your own account, and the Privacy Policy.
{% else %}
Anthropic's consumer terms apply: how long the data is kept, whether it can be used for model training, and when people can review content flagged by safety systems. Consumer plans come without a data processing agreement. Read the Consumer Terms and the Privacy Policy.
{% endif %}
What it costs
{% if engine == "anthropic-api" %} {# No number, and no promise about money. This said "every page is a request billed to your key, and this reading sends of them", which reads as the whole bill and is a floor: reading an archive asks a model in six ways — one call for each page classified, one for each document transcribed, a second reading by the strongest model where a check did not agree, a search for a date where none was read, a reading of what a table measured, and suggestions of new spellings for the vocabulary. Somebody with a budget to get approved read that number, wrote it in, and would have been billed more than twice it. A number this program cannot honour it should not print: what it owes the reader is that model calls cost money, that nothing here limits them, and where the limit can be set. #}
Reading documents calls a model, and every call is billed to the key you set. Nothing in this program limits that, and it cannot tell you what it will come to: it depends on the archive, on which models are chosen on the Settings page, and on prices that are not ours. Watch the spend on the account the key belongs to — a cap is usually set there rather than here — and start with one folder rather than thirty years of them.
{% else %}
Nothing in money: the reading runs under your subscription. It stops at the usage limit and continues where it left off, so a large archive is read over several runs rather than in one.
{% endif %}
Your control
{% if engine != "anthropic-api" %}The model training setting for your account is at claude.ai/settings/data-privacy-controls. A change to it does not apply to data sent before the change. {% endif %}Nothing is sent before you confirm here. What you confirm is this one way of reaching a model, out of the archives named above — change the way, or add the archive of another person, and this page asks again. You can take it back here at any time, and then nothing is sent by this server at all: not by a page, not by a command, not by anything in a crontab.
