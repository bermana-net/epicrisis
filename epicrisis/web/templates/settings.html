The archive over the network
What this means in use

Once, on the server: sudo epicrisis mcp-lock init. It prints a line for your authenticator app — that line is the code's secret, so read it there and send it nowhere.

Then, in a conversation: the assistant hits the lock, asks you for the six digits, and the archive opens. A new conversation asks again; within one it stays open for the window below.

Ending a conversation: ask the assistant to lock the archive. The pass it was given stays written in that conversation, and locking makes it useless to anyone who reads it later.

If you lose the phone with the authenticator: epicrisis mcp-lock off on the server takes the lock away, and mcp-lock init --force sets up a new code. Nothing is lost.

Opening the conversation keeps the opening with whoever made it: a stranger who reached the server would still have no way in. Opening everything is easier to live with and gives that up for the length of the window.
